# Arduino 学习笔记

这个仓库记录了我学习 Arduino 开发的过程，按功能模块整理了各种传感器和执行器的驱动代码。

## 目录结构

- `01-Sensors/` — 各类传感器驱动（超声波、红外、力敏电阻等）
- `02-Actuators/` — 执行器控制（电机、舵机）
- `03-Display/` — 显示模块（OLED）
- `04-Communication/` — 通信协议（蓝牙、串口）
- `05-Integration/` — 组合应用（避障小车、柔顺交互等）

## 学习方式

每个模块都包含：
- 可直接运行的 `.ino` 代码
- 接线说明
- 核心知识点注释
